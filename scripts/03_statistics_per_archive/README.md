# Step 03: counting messages and users in each archive

The counting scripts read `data/output/02_build_database/usenet.db`, and each drawing script reads what the script before it wrote. Messages whose date could not be parsed are excluded from the date filtered statistics.

All of the drawing scripts except [newsgroup_tree.py](newsgroup_tree.py), which writes its trees as text, need the plotting libraries in the optional `viz` dependency group, which is not installed by default. Install it with `uv sync --group viz`.

- [01_count_messages_per_group.py](01_count_messages_per_group.py) counts messages per newsgroup for each of IA, date filtered IA and NB archives. Creates `data/output/03_statistics_per_archive/messages_per_group_ia.csv`, `data/output/03_statistics_per_archive/messages_per_group_ia_date_filtered.csv`  and `data/output/03_statistics_per_archive/messages_per_group_nb.csv`
- [02_plot_messages_per_group.py](02_plot_messages_per_group.py) plots messages in the top 20 groups vs the rest, and the distribution of newsgroups by message count, reading the `messages_per_group_*.csv` files. Prints group statistics to stdout and saves .png files to `data/output/03_statistics_per_archive/plot_messages_per_group/`.
- [03_count_duplicate_messages.py](03_count_duplicate_messages.py) finds *true duplicates*: messages stored more than once in the same mbox file with both the same Message-ID and the same body. Every copy is its own row in the database, so these are rows sharing archive, newsgroup, hashed Message-ID and hashed body. Creates `data/output/03_statistics_per_archive/duplicate_messages_per_group.jsonl`, with one row per duplicated Message-ID (`archive`, `newsgroup`, `hashed_message_id`, `count`), where `count` is the total number of copies present.
- [04_count_messages_per_user.py](04_count_messages_per_user.py) counts messages per user, reported by the hashes the database already holds, so no plain text name or email is written out. Creates `data/output/03_statistics_per_archive/messages_per_user_ia.csv`, `data/output/03_statistics_per_archive/messages_per_user_ia_date_filtered.csv` and `data/output/03_statistics_per_archive/messages_per_user_nb.csv`. Messages with no sender are left out, and counted by `09_count_messages_without_sender.py` instead.
- [05_plot_messages_per_user.py](05_plot_messages_per_user.py) plots posts by the top 100 users vs the rest and the cumulative post distribution by user, reading the `messages_per_user_*.csv` files. Prints user statistics to stdout and saves image files to `data/output/03_statistics_per_archive/plot_messages_per_user/`.
- [06_count_messages_per_date.py](06_count_messages_per_date.py) counts messages per date in each of IA and NB archives. Messages whose date could not be parsed are reported in a row labelled `unknown`. Outputs one file for each archive: `data/output/03_statistics_per_archive/date_count_ia.csv` and `data/output/03_statistics_per_archive/date_count_nb.csv`
- [07_plot_date_counts.py](07_plot_date_counts.py) plots message counts over time (daily, monthly and yearly) for each archive, reading the `date_count_*.csv` files. Saves .png files to `data/output/03_statistics_per_archive/plot_date_counts/`.
- [08_find_conflicting_message_ids.py](08_find_conflicting_message_ids.py) finds Message-IDs that carry more than one distinct body *within* a single archive, i.e. messages that cannot be deduplicated on Message-ID without losing a version. Creates `data/output/03_statistics_per_archive/conflicting_message_ids_within_archive.jsonl`.
- [09_count_messages_without_sender.py](09_count_messages_without_sender.py) counts messages with no sender, per archive and newsgroup. A message has no sender when no name and no email could be read from its From header, which may still be there. Creates `data/output/03_statistics_per_archive/messages_without_sender.jsonl`.
- [newsgroup_tree.py](newsgroup_tree.py) draws the nested newsgroup structure of each archive as an ASCII tree, reading the `messages_per_group_*.csv` files. A supergroup that has an mbox file of its own holds that file's message count in a child node labelled `.`, so it is counted apart from the subgroups. Supergroups without an mbox file of their own get a `.` node counting no messages, unless `--hide-empty-own-mbox` is passed. Creates `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_ia.txt` and `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_nb.txt`
- [newsgroup_tree_gif.py](newsgroup_tree_gif.py) draws the same trees as scrolling animations. Creates `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_ia.gif` and `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_nb.gif`
