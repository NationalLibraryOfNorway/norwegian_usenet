# Step 03: counting messages and users in each archive

The counting scripts read `data/output/02_build_database/ia.db` and `data/output/02_build_database/nb.db`, and each drawing script reads what the script before it wrote. Messages whose date could not be parsed are excluded from the date filtered statistics.

- [01_count_messages_per_group.py](01_count_messages_per_group.py) counts messages per newsgroup for each of IA, date filtered IA and NB archives. Creates `data/output/03_statistics_per_archive/messages_per_group_ia.csv`, `data/output/03_statistics_per_archive/messages_per_group_ia_date_filtered.csv`  and `data/output/03_statistics_per_archive/messages_per_group_nb.csv`. Run with `--overwrite` to rewrite output files that are already there; without the flag each of them is skipped.
- [02_plot_messages_per_group.py](02_plot_messages_per_group.py) plots messages in the top 20 groups vs the rest, and the distribution of newsgroups by message count, reading the `messages_per_group_*.csv` files. One .png is written per archive, for full IA, date filtered IA and NB alike, while the statistics printed against NB are read off the date filtered IA counts. Prints group statistics to stdout and saves .png files to `data/output/03_statistics_per_archive/plot_messages_per_group/`.
- [03_count_duplicate_messages.py](03_count_duplicate_messages.py) finds *true duplicates*: messages stored more than once in the same mbox file with both the same Message-ID and the same body. Every copy is its own row in the database, so these are rows sharing archive, newsgroup, hashed Message-ID and hashed body. Creates `data/output/03_statistics_per_archive/duplicate_messages_per_group.jsonl`, with one row per duplicated Message-ID (`archive`, `newsgroup`, `hashed_message_id`, `count`), where `count` is the total number of copies present. Run with `--overwrite` to rewrite that file; without the flag the script exits without doing anything when it is already there.
- [04_count_messages_per_user.py](04_count_messages_per_user.py) counts messages per user, reported by the `email_id` the archive database already holds. A user is one email address, counted per archive, so the three files below cannot be laid over each other; [user_overlap.py](../05_venn_diagrams/user_overlap.py) in step 05 is what compares the users of the two archives. Creates `data/output/03_statistics_per_archive/messages_per_user_ia.csv`, `data/output/03_statistics_per_archive/messages_per_user_ia_date_filtered.csv` and `data/output/03_statistics_per_archive/messages_per_user_nb.csv`. Each file holds `email_id` and `post_count`. Messages whose sender gave no address are left out, and counted by `09_count_messages_without_sender.py` instead. Run with `--overwrite` to rewrite output files that are already there; without the flag each of them is skipped.
- [05_plot_messages_per_user.py](05_plot_messages_per_user.py) plots messages by the top 100 users vs the rest and the cumulative message distribution by user, reading the `messages_per_user_*.csv` files. The top-users-vs-rest split is drawn twice, as one horizontal bar cut in two (`top_100_users_vs_rest_bar_*.png`) and as a pie of two slices (`top_100_users_vs_rest_pie_*.png`), each written per archive, for full IA, date filtered IA and NB alike, while the cumulative distribution plot and the statistics printed against NB are read off the date filtered IA counts. Each archive is drawn on its own, since a user of one cannot be recognised in the other from these files. Prints user statistics to stdout and saves image files to `data/output/03_statistics_per_archive/plot_messages_per_user/`.
- [06_count_messages_per_date.py](06_count_messages_per_date.py) counts messages per date in each of IA and NB archives. Messages whose date could not be parsed are reported in a row labelled `unknown`. Outputs one file for each archive: `data/output/03_statistics_per_archive/date_count_ia.csv` and `data/output/03_statistics_per_archive/date_count_nb.csv`. Run with `--overwrite` to rewrite output files that are already there; without the flag each of them is skipped.
- [07_plot_date_counts.py](07_plot_date_counts.py) plots message counts over time (daily, monthly and yearly) for each archive, reading the `date_count_*.csv` files. Saves .png files to `data/output/03_statistics_per_archive/plot_date_counts/`.
- [08_find_conflicting_message_ids.py](08_find_conflicting_message_ids.py) finds Message-IDs that carry more than one distinct body *within* a single archive, i.e. messages that cannot be deduplicated on Message-ID without losing a version. Creates `data/output/03_statistics_per_archive/conflicting_message_ids_within_archive.jsonl`. Run with `--overwrite` to rewrite that file; without the flag the script exits without doing anything when it is already there.
- [09_count_messages_without_sender.py](09_count_messages_without_sender.py) counts messages with no sender, per archive and newsgroup. A message has no sender when no address could be read from its From header, which may still be there and may still carry a display name: a user is an email address, so a From header giving a name and nothing else counts here. Creates `data/output/03_statistics_per_archive/messages_without_sender.jsonl`. Run with `--overwrite` to rewrite that file; without the flag the script exits without doing anything when it is already there.
- [nb_directory_hierarchy.py](nb_directory_hierarchy.py) draws the directory hierarchy of each NB source as it stands in `data/input/nb/unzipped_data`, as `tree` would print it, rather than the newsgroup names the parse builds from it. Creates one text file per source, named after it, in `data/output/03_statistics_per_archive/nb_directory_hierarchy/`.
- [newsgroup_tree.py](newsgroup_tree.py) draws the nested newsgroup structure of each archive as an ASCII tree, reading the `messages_per_group_*.csv` files. A supergroup that has an mbox file of its own holds that file's message count in a child node labelled `.`, so it is counted apart from the subgroups. Supergroups without an mbox file of their own get a `.` node counting no messages, unless `--hide-empty-own-mbox` is passed. Creates `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_ia.txt` and `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_nb.txt`
- [newsgroup_tree_gif.py](newsgroup_tree_gif.py) draws the same trees as scrolling animations. Creates `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_ia.gif` and `data/output/03_statistics_per_archive/newsgroup_tree/newsgroup_tree_nb.gif`
