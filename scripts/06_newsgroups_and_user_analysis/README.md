# Step 06: newsgroups and user analysis

- [00_newsgroup_user_jaccard_overlap.py](00_newsgroup_user_jaccard_overlap.py) computes the Jaccard overlap between the user sets of every pair of newsgroups, reading `data/output/02_build_database/usenet.db`. A user is one hashed email address. Creates one row per newsgroup pair sharing at least one user (`newsgroup_a`, `newsgroup_b`, `users_a`, `users_b`, `shared_users`, `jaccard`) in `data/output/06_newsgroups_and_user_analysis/newsgroup_user_jaccard_overlap_nb.csv`, `data/output/06_newsgroups_and_user_analysis/newsgroup_user_jaccard_overlap_ia_date_filtered.csv` and `data/output/06_newsgroups_and_user_analysis/newsgroup_user_jaccard_overlap_nb_and_ia_date_filtered.csv`
- [00_count_references_between_newsgroups.py](00_count_references_between_newsgroups.py) counts the references running from each newsgroup to each other newsgroup as a directed edge list, reading `data/output/02_build_database/usenet.db`. Every reference from a message in one newsgroup to a message held by another adds one to the pair's edge. References to messages not in the read body of messages are counted under a placeholder `unknown` newsgroup, and references within a newsgroup are left out. Creates one row per (from, to) pair (`from_newsgroup`, `to_newsgroup`, `number_of_references`) in `data/output/06_newsgroups_and_user_analysis/newsgroup_reference_counts_nb.csv`, `data/output/06_newsgroups_and_user_analysis/newsgroup_reference_counts_ia_date_filtered.csv` and `data/output/06_newsgroups_and_user_analysis/newsgroup_reference_counts_nb_and_ia_date_filtered.csv`
- [00_count_referenced_messages_between_newsgroups.py](00_count_referenced_messages_between_newsgroups.py) counts how many distinct messages in each newsgroup each other newsgroup references, with the same edge list format and the same `unknown` placeholder as the script above: a message referenced by five hundred messages adds five hundred to the edge there and one here. Creates `data/output/06_newsgroups_and_user_analysis/newsgroup_referenced_message_counts_nb.csv`, `data/output/06_newsgroups_and_user_analysis/newsgroup_referenced_message_counts_ia_date_filtered.csv` and `data/output/06_newsgroups_and_user_analysis/newsgroup_referenced_message_counts_nb_and_ia_date_filtered.csv`
- [00_topic_modelling.py](00_topic_modelling.py) uses BERTopic and the text embeddings generated in the previous step to find topics in the selected newsgroups
