# Step 06: graphs and references

The scripts are numbered in pairs: each drawing script reads the edge list the script before it writes.

The drawing scripts need the plotting libraries in the optional `viz` dependency group, which is not installed by default. Install it with `uv sync --group viz`.

Both figures are drawn with vis-network, which brings its own physics: each edge is a spring pulling towards the distance the layout placed it at, so a newsgroup dragged aside takes the ones it is joined to along. In the reference graph a newsgroup is left where it is dropped, since it is one crowd of newsgroups referencing each other; double-clicking it hands it back to the physics.

- [01_newsgroup_user_jaccard_overlap.py](01_newsgroup_user_jaccard_overlap.py) computes the Jaccard overlap between the user sets of every pair of newsgroups, reading `data/output/02_build_database/usenet.db`. A user is one hashed email address. Creates one row per newsgroup pair sharing at least one user (`newsgroup_a`, `newsgroup_b`, `users_a`, `users_b`, `shared_users`, `jaccard`) in `data/output/06_graphs_and_references/newsgroup_user_jaccard_overlap_nb.csv`, `data/output/06_graphs_and_references/newsgroup_user_jaccard_overlap_ia.csv` and `data/output/06_graphs_and_references/newsgroup_user_jaccard_overlap_nb_and_ia.csv`
- [02_plot_newsgroup_overlap_graph.py](02_plot_newsgroup_overlap_graph.py) draws a graph of newsgroups, with edges based on user overlap. The script reads a `newsgroup_user_jaccard_overlap_*.csv` file written above. A pair becomes an edge if it clears both `--jaccard-threshold` and `--min-shared-users`, and the layout places newsgroups at a distance of 1 - jaccard from each other. Every newsgroup in the input file is drawn and named on the picture. Saves an interactive .html figure, named after the input file and the two thresholds, to `data/output/06_graphs_and_references/plot_newsgroup_overlap_graph/`. (The current script is adapted for the current default input file, the graph layout may look bad if input file is changed)
- [03_count_references_between_newsgroups.py](03_count_references_between_newsgroups.py) counts what runs from each newsgroup to each other newsgroup as directed edge lists, reading `data/output/02_build_database/usenet.db`. References to messages not in the read body of messages are counted under a placeholder `unknown` newsgroup, and references within a newsgroup are left out. Creates one row per (from, to) pair (`from_newsgroup`, `to_newsgroup`, `number_of_references`), weighted two ways for each of the three bodies of messages, in `--output-directory` (`data/output/06_graphs_and_references/` by default).
  - The reference counts add one to the pair's edge for every reference a message in the first newsgroup makes to a message held by the second: `newsgroup_reference_counts_nb.csv`, `newsgroup_reference_counts_ia.csv` and `newsgroup_reference_counts_nb_and_ia.csv`
  - The referenced message counts count how many distinct messages of the second newsgroup are referenced at all, so a message referenced by five hundred messages adds five hundred to the edge above and one here: `newsgroup_referenced_message_counts_nb.csv`, `newsgroup_referenced_message_counts_ia.csv` and `newsgroup_referenced_message_counts_nb_and_ia.csv`
- [04_plot_newsgroup_reference_graph.py](04_plot_newsgroup_reference_graph.py) draws a directed graph of newsgroups, with arrows for the references between them, reading a reference edge list CSV written above and the `messages_per_group_*.csv` files from step 03, which size the vertices by message count. An edge is drawn if it carries at least `--min-references` references, and its width follows the count. The `unknown` placeholder is drawn as a diamond unless `--exclude-unknown` is flagged, and `no.general` is left out with its edges if `--exclude-general` is flagged. Every newsgroup drawn is named on the picture. Saves an interactive .html figure, named after the input file, the two exclusion flags and the threshold, to `data/output/06_graphs_and_references/plot_newsgroup_reference_graph/`.
