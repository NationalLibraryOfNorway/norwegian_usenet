# Step 08: embed messages

These scripts read the mbox files rather than the database, since embedding needs the message text itself, which the database stores only as a hash.

- [00_select_newsgroups.py](00_select_newsgroups.py) writes the top 50 newsgroups by combined unique message count, reading `data/output/04_compare_message_bodies/ia_nb_content_comparison.csv` (from step 04) and keeping only groups where both archives contribute unique messages. Creates `data/output/08_make_embeddings/newsgroups_for_selection.jsonl`, meant as candidates when choosing the `--selection` newsgroups for the scripts below.
- [01_embed_messages.py](01_embed_messages.py) makes text embeddings for each message in a selection of newsgroups, with a sentence-transformers model. `--archive` picks the messages to embed: `nb` (the default), `ia` or `both`. The IA archive runs past the NB one at both ends, so only IA messages inside the NB date span are embedded; the database says which those are, and they are read from `data/input/internet_archive/utf_8_data` at the positions it gives. Writes the embeddings, and the positions they came from, to `data/output/08_make_embeddings/<model>/`, one file per newsgroup and archive (`<newsgroup>_nb.npy` and `<newsgroup>_ia.npy`), so the scripts below can read either archive on its own. Run with `--overwrite` to re-embed newsgroups already written there; without the flag each newsgroup and archive already embedded is skipped.
- [02_reduce_embeddings.py](02_reduce_embeddings.py) reduces the embeddings to 2 dimensions, and caches the result in `data/output/08_make_embeddings/<reduction>_embeddings/<model>/`, under a name built from the `--selection` newsgroups and `--archive`. `--reduction` picks the algorithm: `tsne` (the default), which reduces from a PCA initialisation at the `--perplexity` of 50 that step 09 fits `topeax` on, or `umap`, and each caches in its own directory. `--archive` picks the messages to reduce: `nb` (the default), `ia` or `both`, and each gets its own cache file, since both algorithms lay the messages they are given out against each other. Run with `--overwrite` to recompute and rewrite that cache file; without the flag the script exits without doing anything when it is already there.
- [03_visualize_embeddings.py](03_visualize_embeddings.py) plots those 2-dimensional embeddings as an interactive Plotly scatter plot, coloured by newsgroup and shaped by archive. `--archive` picks which messages to plot: `nb` (the default), `ia` or `both`, and `--reduction` which of 02's reductions to read, `tsne` (the default) or `umap`; the cache read is the one 02 wrote for that same `--selection`, `--archive` and `--reduction`. The legend holds one entry per newsgroup and archive, or one per newsgroup covering every archive plotted when `--flatten-legend` is flagged. A figure of a single archive names it in neither the title nor the legend, and holds one entry per newsgroup whatever that flag says. With `--plot-centroids` the mean position of the messages of each newsgroup is drawn over the scatter, as a marker with a black outline, labelled in black with the newsgroup name, one per newsgroup and averaged over every archive plotted. Opens in a browser, and with `--save-fig` also writes a `.png` of the scatter, without the message texts of the hover labels, next to the cache it was plotted from, named after it with a `_centroids` suffix when `--plot-centroids` is flagged.
- [04_visualize_newsgroup_centroids.py](04_visualize_newsgroup_centroids.py) averages the message embeddings of every newsgroup in `data/output/08_make_embeddings/<model>/` into one embedding per newsgroup and archive, and plots them as an interactive Plotly scatter plot, one labelled point per newsgroup, coloured and shaped by archive. `--archive` picks the messages to average: `nb` (the default), `ia` or `both`. Unlike 02 the points are projected with PCA, since one point per newsgroup is too few for UMAP or t-SNE. Opens in a browser, and with `--save-fig` also writes a `.png` to `data/output/08_make_embeddings/newsgroup_centroids/<model>/`; `--no-show` leaves the browser out.
- [05_newsgroup_centroid_similarity.py](05_newsgroup_centroid_similarity.py) writes the cosine similarity between every pair of newsgroup centroids, averaging the message embeddings of every newsgroup in `data/output/08_make_embeddings/<model>/` the same way 04 does, one centroid per newsgroup and archive. `--archive` picks the messages to average: `nb` (the default), `ia` or `both`, and a newsgroup carries the archive in its name when both are averaged. Creates one row per pair (`newsgroup_a`, `newsgroup_b`, `messages_a`, `messages_b`, `cosine_similarity`), sorted by descending similarity, in `<output-directory>/<model>/centroid_similarity_<archive>.csv` (`data/output/08_make_embeddings/newsgroup_centroid_similarity/` by default), and rewrites it on every run. Also prints how many centroids and pairs there are, and the `--top-n` (20 by default) pairs with the highest and the lowest similarity between their centroids.
