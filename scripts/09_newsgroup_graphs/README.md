# Step 09: newsgroup graphs

These scripts are unnumbered because they are independent of each other and can be run in any order.

- [message_reference_resolution.py](message_reference_resolution.py) counts the references each archive cannot resolve on its own but the other can, and the ones pointing at a posting neither archive kept, split by the archive that cited them, alongside the message-ID overlap between the archives, reading `data/output/02_build_database/usenet.db`. The IA archive is restricted to the NB date span. Creates `data/output/09_newsgroup_graphs/ia_nb_message_id_overlap_date_filtered.json`, with the per-newsgroup ID overlap in `data/output/09_newsgroup_graphs/ia_nb_message_id_comparison_date_filtered.csv`
- [newsgroup_user_jaccard_overlap.py](newsgroup_user_jaccard_overlap.py) computes the Jaccard overlap between the user sets of every pair of newsgroups, reading `data/output/02_build_database/usenet.db`. A user is one hashed email address. Creates one row per newsgroup pair sharing at least one user (`newsgroup_a`, `newsgroup_b`, `users_a`, `users_b`, `shared_users`, `jaccard`) in `data/output/09_newsgroup_graphs/newsgroup_user_jaccard_overlap_nb.csv`, `data/output/09_newsgroup_graphs/newsgroup_user_jaccard_overlap_ia_date_filtered.csv` and `data/output/09_newsgroup_graphs/newsgroup_user_jaccard_overlap_nb_and_ia_date_filtered.csv`
- [count_references_between_newsgroups.py](count_references_between_newsgroups.py) counts what runs from each newsgroup to each other newsgroup as a directed edge list, reading `data/output/02_build_database/usenet.db`. References to messages not in the read body of messages are counted under a placeholder `unknown` newsgroup, and references within a newsgroup are left out. Creates one row per (from, to) pair (`from_newsgroup`, `to_newsgroup`, `number_of_references`) per body of messages, in `--output-directory` (`data/output/09_newsgroup_graphs/` by default).
  - `--count references`, the default, adds one to the pair's edge for every reference a message in the first newsgroup makes to a message held by the second. Creates `newsgroup_reference_counts_nb.csv`, `newsgroup_reference_counts_ia_date_filtered.csv` and `newsgroup_reference_counts_nb_and_ia_date_filtered.csv`
  - `--count referenced-messages` counts how many distinct messages of the second newsgroup are referenced at all: a message referenced by five hundred messages adds five hundred to the edge above and one here. Creates `newsgroup_referenced_message_counts_nb.csv`, `newsgroup_referenced_message_counts_ia_date_filtered.csv` and `newsgroup_referenced_message_counts_nb_and_ia_date_filtered.csv`
