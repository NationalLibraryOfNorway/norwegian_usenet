# Usenet notebooks

This folder contain Marimo notebooks, used for comparison and interactive exploration of the Usenet data from the National Library of Norway (NB) and Internet Archive (IA).

Marimo notebooks are very similar to Jupyter notebooks but are stored as python files (`.py`) instead of `.ipynb`, which comes with some advantages:
- reactive execution ensures cells run in the correct order
- script validation to e.g. ensuring duplicate variables,
- version control

The notebooks can be [run locally](https://docs.marimo.io/getting_started/installation/) or in Molab(href to our Molab notebooks).
